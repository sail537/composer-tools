# 节奏插值

在两个节奏之间插值，生成任意数量的中间节奏，用五线谱显示并导出 MIDI。
算法与 IRCAM OpenMusic 的 `INTERPOLATION` 同构。

## 位置

- 网页源码：`tools/rhythm-interp-demo.html`
- 核心算法：`tools/rhythm-interp-core.js`
- 单元测试：`tools/test-rhythm-interp-core.mjs`
- 记谱语义校验：`tools/test-notation-semantics.mjs`（把生成的 ABC 交回 abcjs 读一遍再比对）
- 依赖：`tools/vendor/abcjs/`（MIT）

## 输入

时值以**全音符 = 1**：`1/4` = 四分音符 = 1 拍，`1/8` = 八分音符，`1/12` = 三连音八分音符。
空格或逗号分隔。

- **休止符**：写 `z1/8` 或 `r1/8`；只写 `z` 就沿用前一个时值，出现在开头按 `1/4`。
  只有 A、B 两端都是休止的位置，插值结果才是休止——「音符渐变成休止」在记谱上没法表达。
- **多声部**：点「添加声部」增加一行，每行一个 A/B 对。多声部会一起插值，
  五线谱按总谱显示（`%%score {1 2 …}`），MIDI 按每声部一条轨导出。
  逐项时值（`dx`）要求**同一个声部内** A、B 长度相同；时间弯曲（`warp`）无此限制。

## 算法

与 OM 的 `INTERPOLATION` 同构：`w(t, curve) = t ^ (e ^ (-curve))`，
`C(t) = A + (B − A) * w(t, curve)`。`curve = 0` 线性，`> 0` 先快后慢，`< 0` 先慢后快。

记谱用**全局量化器**（`quantizeNotation`）：把节奏切成若干「记谱层」片段做动态规划，
代价 = Σ(累计漂移 / 最小音符值)² + 括号 + 延音线 + 节拍错位。它能表达的东西：

- **混合时值连音**：三连音里夹四分 → `(3:2:2B2 B`
- **跨小节延音线**：`B3 B- | B2`
- **拍号与节拍层级**：`M:` 跟随拍号，复拍子（6/8 等）把附点拍当一拍，
  连音括号优先落在一拍之内
- **末小节补休止**：不足一小节时自动补满（可关闭）
- **连音只做精确表达**：容差 1%，凑不出来就老实退回网格量化并如实报误差，
  不写 `(9:8:1B` 这种硬凑的记谱

### abcjs 的三条硬限制（实测）

1. `(P:Q:R` 的 **P 只能是 0–9**。P ≥ 10 **静默失效**（不报错、不警告，整组退化成普通时值），
   所以连音比例一律先约分（12:8 → 3:2），P > 9 的层不生成。
2. **R 可以是多位数**（`(3:2:12`），混合时值连音因此可写。
3. **括号不能嵌套**，所以嵌套连音只能摊平。`9:4` 可以读作 `3:2 套 3:2`，
   在 UI 里会写出来；但 `3:2` 套 `3:2` 里的内层若再细分到不同的单位，
   数学上没法摊成一个括号，这种情况只能退回网格量化并报误差。

嵌套连音也可以直接写成乘积：`3:2*3:2` 会自动约分成 `9:4`。

## 导出

- **MIDI**：每个起点一个音、音长用时值，默认走 GM 打击乐通道（木鱼）；
  多声部写成 format 1，第一轨放速度/拍号，其余每声部一轨。休止不发声。
- **五线谱 SVG**：可导出 A、B 或任意中间状态。

## 测试

```
node tools/test-rhythm-interp-core.mjs      # 46 项
node tools/test-notation-semantics.mjs      # 22 项（abcjs 回读校验）
```

`test-notation-semantics.mjs` 是这套东西里最有价值的一道防线：它把生成的 ABC 交回 abcjs
解析，按连音括号还原每个音的真实时长，再和原始节奏逐点比对。P ≥ 10 静默失效、
嵌套括号被吞、休止被算错位置——这些都不会报错，只能靠回读发现。
