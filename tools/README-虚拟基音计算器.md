# 虚拟基音计算器

输入一个和弦，算出它的**虚拟基音**（virtual fundamental）——那个能让和弦里每个音都
（近似）成为其整数倍泛音的基音。结果的音名、频率、以及每个音对应的泛音序号都会列出。

## 位置

- 网页源码：`tools/virtualfund-demo.html`
- 核心算法：`tools/virtualfund-core.js`
- 单元测试：`tools/test-virtualfund-core.mjs`

直接双击 `virtualfund-demo.html` 即可（需要与 `interpolation-core.js`、
`virtualfund-core.js` 在同一目录，通过相对路径加载）。

## 算法的出处

移植自 IRCAM OpenMusic 的 **OMTristan** 库（Esquisse 库里有同源实现）：

| OM 函数 | 本实现 | 源码位置 |
|---|---|---|
| `virtual-fund` / `virt-fund` | `analyze()` | `OMTristan/sources/TMlibrairie-OM.lisp:2337` |
| `tolerant-gcd` | `tolerantGCD()` | `OMTristan/sources/TMlibrairie-OM.lisp:2277` |
| `virt-fund-step` | `virtualFundSweep()` | `OMTristan/sources/TMlibrairie-OM.lisp:2382` |

`tolerant-gcd` 是 Gérard Assayag 1993 年的「带容差的浮点最大公约数」，用分支定界实现：

1. 容差以音分给出，换算成比例 `grid-ratio = 2^(cents/1200) − 1`；
2. 候选基音区间初始化为 `[0.1, (1+ratio) × min(各音频率)]`；
3. 对每个音，把它能接受的 `频率 / 基音` 商圈成一个整数区间，从**最小**的商开始试，
   每试一个就收窄基音区间；
4. 全部音走完，返回剩余区间的中点；全试完都不行则无解。

因为商是**从小到大**试的，返回的是**最高**的那个基音——所以结果永远不会高于和弦的最低音。

## 用之前要知道的四件事

1. **容差不是精度旋钮，是答案旋钮。** C4 E4 G4 在 50¢ 下解出 C2（泛音 4:5:6），
   在 100¢ 下解出 E2（泛音 3:4:5）——两个都是合法答案，不是同一个答案的粗略版。
   所以界面上把容差放显眼位置，并显示每个音的泛音序号。
2. **0¢ 时平均律和弦基本无解。** 十二平均律不是纯律：大三度偏 13.7 音分、五度偏 2 音分，
   频率比不是有理数，因而不存在精确的公共基音。这是常态，不是 bug。
3. **它是有理逼近，不是心理声学模型。** 这是「谐和性归属」度量，不是 Terhardt 的
   virtual pitch（那还要考虑响度、临界带、泛音衰减）。用在作曲决策上够用。
4. **大容差会退化。** 容差接近一个半音时，几乎任何和弦都能「解」出来，结果失去区分度。
   建议上限定在 75¢ 左右。
5. **容差太小会降到亚音。** OM 的候选下界是 0.1 Hz，所以只要容差足够小，总能凑出一个
   「解」来，但那个基音可能在 1–10 Hz、泛音序号高达两三百（C4 E4 G4 @1¢ → 5.68 Hz，
   泛音 46:58:69）。程序会如实标出「亚音」并不画五线谱、不在扫描图上画它。
   要拿到有音乐意义的答案，容差至少要十几音分。

## 界面

1. **和弦输入**：88 键钢琴（A0–C8）点选、文本框输入 `60 64 67` 或 `C4 E4 G4`、
   六个示例和弦。示例按钮会替换当前和弦。
2. **分析参数**：容差滑杆（默认 50¢，与 OM 的 `:initvals` 一致）、五线谱上泛音序列的长度、
   扫描上限。
3. **虚基音**：音名 + 频率 + MIDI + 泛音序号 + 最大偏差，下面是逐音对照表
   （每个和弦音 → 频率 → 泛音序号 N → N×f₀ → 偏差 → 相对容差条）。
4. **五线谱**：左＝输入和弦，中＝虚基音，右＝以虚基音为 1 号的泛音序列。
   和弦各音应当与序列中的某几个音重合。
5. **精度扫描**：横轴容差（0 → 上限，步长 1¢），纵轴虚基音。看得到答案的平段与跳变。
6. **导出**：MIDI（虚基音 + 和弦 / 只虚基音 / 泛音序列，微分音走 Pitch Bend 或 MTS）、
   五线谱 SVG。

还可以用 WebAudio 试听：虚基音、和弦、泛音序列。

## 与 OM 的差异

- OM 的 `virtual-fund` 的 `cents` 参数收标量也收列表（收列表时返回一列结果）；
  这里只做标量版本，另配一个 `virtualFundSweep()` 做扫描。
- 本实现额外加了递归节点预算（默认 20 万），用来挡住病态输入导致的组合爆炸；
  OM 原版没有这道保护。超预算时返回 `reason: 'budget'`。
- 只实现唯一解。OM 还有 Delerue 写的 `virt-fund-multi`，会返回多个解
  （每个解是一个 chord-seq，最低音是虚基音、其余是原和弦的子集），本 demo 不含。
